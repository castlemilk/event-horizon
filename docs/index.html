// capabilities

Complete Universal Wi-Fi & Satellite Network Suite

From raw USB bulk endpoints to user-space virtual network tunnels, RF channel heatmaps, and autonomous AI fleet management.

Hardware HAL

USB Autodetect & ZeroCD Eject

Scans the USB bus for Wi-Fi dongles (AicSemi AIC8800 Wi-Fi 6, Realtek RTL8811/12/21/32, MediaTek MT7601U) and auto-ejects storage mode into native WLAN mode.

Wi-Fi 6 / 2.4 & 5 GHz

RF Spectrum & Channel Analyzer

Live 2.4 GHz & 5 GHz spectrum channel occupancy graphs, co-channel density penalty scoring, and automated 1-click clean channel recommendations.

Smart Routing

Multi-WAN Policy & Auto-Failover

Manage default gateway priority between Host Wi-Fi (en0) and USB Wi-Fi (utun10) with an automated watchdog that fails over seamlessly if pings drop.

Line-Rate Bandwidth

Multi-Stream Speedtest Engine

Concurrent multi-worker HTTP download & upload throughput benchmarking, interface-bound socket testing, and sub-millisecond bufferbloat jitter measurement.

utun10 Architecture

L4 User-Space Protocol Bridge

Full TCP 3-way handshake responder, UDP datagram multiplexing, RFC 1035 DNS A-record resolver, and RFC 5905 NTP time synchronization on virtual tunnel interfaces.

Enterprise Security

WPA2/WPA3 Hardware Handshakes

Derives cryptographic PMK keys via PBKDF2 and executes the 4-way EAPOL handshake directly against target access points and Starlink hotspots.

macOS Core

3-Tier Hardware Topology Map

Real-time visual map bridging USB Physical Driver → macOS BSD Interface (en0, en14, utun10) → Network Endpoint with live link state at every tier.

AI Native

Model Context Protocol (MCP)

Integrated JSON-RPC 2.0 stdio server equipping Claude Desktop, Cursor, Antigravity, and Codex with autonomous network diagnostics and Wi-Fi management tools.

Phase 1 & 2 Capabilities

Spectrum Telemetry & Multi-WAN Failover

Eliminate Wi-Fi congestion and connection drops. Event Horizon continuously profiles 2.4 GHz and 5 GHz spectrum channels while managing dual-interface default gateway priority.

1-Click Clean Channel Recommendation

Calculates co-channel interference and adjacent channel overlap to pinpoint the optimal channel for your router.

Zero-Stall Gateway Failover Watchdog

Automatically switches system routing from host Wi-Fi to Starlink USB Wi-Fi if gateway ICMP pings fail.

Multi-Stream Line-Rate Speedtest

Benchmark interface-bound throughput up to 1+ Gbps with sub-millisecond bufferbloat jitter measurement.

// agent interface

Your AI agent can drive the dongle

Event Horizon ships an MCP server speaking JSON-RPC 2.0 over stdio. Point Claude, Gemini or any MCP-capable agent at bin/usbwifi-mcp and it can scan, connect and diagnose the link itself — no UI clicks required.

  • usbwifi_get_hardware_topology3-tier USB → interface map
  • usbwifi_get_telemetrylive rates & interface stats
  • usbwifi_scan_hotspots802.11 beacon scan
  • usbwifi_connect_hotspotWPA2/WPA3 associate
  • usbwifi_run_diagnosticsRTT + packet loss
  • usbwifi_get_uptimestability & reconnects
.agents/mcp_config.json
{
  "mcpServers": {
    "usbwifi": {
      "command": "bin/usbwifi-mcp",
      "args": [],
      "env": { "DAEMON_URL": "http://127.0.0.1:8990" }
    }
  }
}

Build from source
git main
# requires Go 1.22+, Swift 6, Task
git clone https://github.com/castlemilk/event-horizon
cd event-horizon
task build          # builds .app + DMG + MCP server
open "build/Event Horizon.app"
Daemon + MCP quickstart
headless

Run the daemon on its own — the HTTP API is all you need for scripting or the MCP server.

# run just the Go daemon + API
go build -o bin/usbwifi ./cmd/usbwifi
./bin/usbwifi --ssid "CNH Starlink" --port 8990
# → http://127.0.0.1:8990/api/wifi/scan
  • ✓macOS 14 or newer, Apple Silicon (arm64)
  • ✓A USB Wi-Fi dongle: AIC8800, Realtek, or UGREEN
  • ✓Go 1.22+ and Swift 6 toolchain to build from source
