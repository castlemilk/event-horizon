## Event Horizon 1.0.0

A USB Wi-Fi driver for macOS that never touches the kernel. Drives the
UGREEN AX900 (AICSEMI AIC8800D80) entirely from user space: firmware
bootstrap, LMAC control plane, RF calibration, scan, association, the WPA2
4-way handshake, DHCP and an IP bridge into a `utun`. SIP stays on. No kernel
extension.

The story of how it was built: https://benebsworth.com/blog/usb-wifi-in-userspace/

### What's in the DMG

- **Event Horizon.app**, signed with Developer ID and notarised by Apple.
  Drag it to Applications.
- `usbwifi` (the driver + daemon + CLI) and `usbwifi-mcp` (an MCP server so
  Claude, Codex or any MCP-capable agent can drive the dongle), both inside
  the app bundle at `Contents/Resources/`.

### Requirements

- macOS 14 or newer on Apple Silicon.
- A UGREEN AX900 / AIC8800D80 dongle.
- `innoextract` (`brew install innoextract`) for the one-time firmware step.

### First run

The app does not ship firmware. Three of the four blobs come from a public
repo and the fourth is on the dongle itself, so a one-time step produces
them:

```bash
EH="/Applications/Event Horizon.app/Contents/Resources"
"$EH/usbwifi" firmware fetch          # three public blobs, SHA-256 verified
# plug the dongle in fresh: it mounts as a small disk named UGREEN
"$EH/usbwifi" firmware carve          # carves the fourth from the dongle's own driver
```

Then launch the app and it will ask for administrator privileges once, to
claim the USB device and create the `utun`.

### Known limitations

- One chip is supported (AIC8800D80). The app detects Realtek and MediaTek
  dongles but does not drive them.
- The chip allows one reset per firmware flash and never falls back to its
  flashable mode on its own, so re-flashing means physically unplugging and
  replugging the dongle. The app tells you when.
- Bring-up from a cold replug takes about 32 seconds, most of it the
  firmware upload.
