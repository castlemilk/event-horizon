# Design Context: USB WiFi & Network Manager

## Project Baseline
- **Application**: USB WiFi & Network Manager (`USBWiFiManager`)
- **Platform**: macOS 14+ (Apple Silicon `arm64`)
- **Architecture**: SwiftUI-first + Go libusb/netstat daemon backend
- **Target Audience**: System administrators, network engineers, hardware tinkerers, mobile workers, and macOS power users managing external USB Wi-Fi dongles (Realtek, AIC, ASIX) alongside built-in Wi-Fi and Ethernet.

## Brand Personality & Tone
- **Tone**: Utilitarian, Precision System Utility & Native Desktop.
- **Aesthetic**: Authentic Apple macOS System Utility (Clean window vibrancy, SF Pro/SF Mono typography, precise micro-metrics, zero AI-slop containers).
- **Core Principles**:
  1. **Clarity**: Unambiguous hardware topology, clear network interface names (`en0`, `en14`, `utun4`), real-time ping RTT latency, and bandwidth rates.
  2. **Deference**: Live network state and hardware topology take center stage; UI step back into macOS system materials.
  3. **Depth**: System materials, subtle translucency (`.regularMaterial`), and native control groupings.
